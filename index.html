JavaScript Cheat Sheet

JavaScript Introduction

1. JavaScript Can Change HTML Content

Example Code:


            <p id="demo">JavaScript can change HTML content.</p>

            <button type="button" onclick='document.getElementById("demo").innerHTML = "Hello JavaScript!"'>
                Click Me!
            </button>

Output:

JavaScript can change HTML content.

Remember: The example above "finds" an HTML element (with id="demo"), and changes the element content (innerHTML) to "Hello JavaScript":

2. JavaScript Can Change HTML Attribute Values

Example Code:


                <button onclick="document.getElementById('myImage').src='pic/on.jpg'">Turn on the light</button>

                <img id="myImage" src="pic/off.jpg" style="width:100px">

                <button onclick="document.getElementById('myImage').src='pic/off.jpg'">Turn off the light</button>

Output:

Remember: In this case JavaScript changes the value of the src (source) attribute of an image.

3. JavaScript Can Change HTML Styles (CSS)

Example Code:


            <p id="demo">JavaScript can change the style of an HTML element.</p>

            <button type="button" onclick="document.getElementById('demo').style.fontSize='35px'">Click Me!</button>

Output:

JavaScript can change the style of an HTML element.

Remember: Changing the style of an HTML element, is a variant of changing an HTML attribute:

4. JavaScript Can Hide HTML Elements

Example Code:


            <p id="demo">JavaScript can hide HTML elements.</p>

            <button type="button" onclick="document.getElementById('demo').style.display='none'">Click Me!</button >

Output:

JavaScript can hide HTML elements.

Remember: Hiding HTML elements can be done by changing the display style.

5. JavaScript Can Show HTML Elements

Example Code:


        <p id="demo" style="display:none">Hello JavaScript!</p>

        <button type="button" onclick="document.getElementById('demo').style.display='block'">
            Click Me!
        </button>

Output:

Hello JavaScript!
